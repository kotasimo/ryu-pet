# りゅう 動画分析ノート

犬の動画を見ながら、特徴点と撫でた区間を手動で記録するブラウザ内ツールです。Issue #1 の MVP として、動画の読み込み、再生操作、特徴点の時系列、JSON の保存と再読み込みを実装しています。動画はアップロードされません。

## 起動

Node.js 20.19 以上または 22.12 以上を用意し、リポジトリで実行します。

```sh
npm install
npm run dev
```

表示されたローカル URL をブラウザで開いてください。`npm run build` で型チェックと本番ビルドができます。

## 使い方

1. MP4 またはブラウザで再生できる MOV を開きます。
2. 再生、停止、シーク、速度変更で時刻を選びます。特徴点を選択し、動画上をクリックします。同じ時刻・部位のクリックで座標を更新できます。
3. 撫でた区間の開始と終了を現在時刻で記録し、接触部位・方向・観察メモを入力します。
4. 表とグラフで記録を確認し、JSON を書き出します。JSON を再読み込みした後は、同じ動画を再接続してください。

## データと制約

- JSON は `version: 1` です。動画のファイル名、種類、サイズ、長さ、幅と高さ、特徴点の時刻と正規化座標、接触区間を保存します。動画本体は含みません。
- 特徴点の左右は**画面上で見た左右**です。座標は動画画面に対する 0〜1 の比率です。
- 「1コマ」は 1/30 秒のシークで、厳密なフレーム送りではありません。表示フレームは動画のフレームレート、キーフレーム、ブラウザのデコードに依存します。
- MOV は拡張子だけでは再生可否が決まりません。ブラウザ非対応のコーデックの場合は、元ファイルを残したまま H.264 の MP4 など再生可能な形式に変換してください。
- グラフの頭頂部との距離は映像上の相対距離です。カメラ移動、ズーム、頭の角度、遠近に影響されるため、実際の移動量を表しません。
- 撫でた区間と動きは別々に記録します。撫でたことが特定の動きを引き起こしたと自動判定しません。感情や快適さのラベルも付けません。
- 個人の写真・動画はリポジトリに入れないでください。動画拡張子は `.gitignore` に登録しています。

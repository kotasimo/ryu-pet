# 自律再生モデル: 写真308・310と動画3

Issue #4の最新コメントに従い、接触操作から独立した短い再生デモを `/` に配置した。旧撫で操作版は `/pet` に残し、今回の画質比較に使った。顔の向きを大きく横顔へ変えることは目標にせず、写真で自然に表現できる正面から小さな斜め向きに限定した。

## 実素材と処理

- **外見**: 同じ画角・照明に近い写真308と310。前者の実写真レイヤーを基準に、両写真で目、鼻、耳、口、頬、輪郭の対応点を合わせる。薄板スプラインによる幾何学的な中間姿勢を33枚生成し、背景の一部を輪郭マスクで除く。二枚のテクスチャの混合は対応位置合わせ後の短い区間だけに制限した。中間画像は実撮影フレームではなく、実写真間の**推定された見た目**。
- **時間方向**: 動画3の2D頭部テクスチャ追跡。3.4〜4.0秒付近と7.6〜8.8秒付近の信頼度が足りるサンプルのみを読み込む。再生時は位置・面内角を2Dに写す。横向きの度合いは動画から測定できていないため、写真間の進行量と区間間の待ち時間は**制作上の補間**。
- **表情**: 写真310では308と視線・目元・口元の見かけが異なる。独立したまばたき、口の開閉、耳の動きは今回の再生では作っていない。これらを動画から抽出できたとは主張しない。

再生成コマンド（実ファイルの絶対パスはローカルで与え、Gitに書かない）:

```sh
python -m pip install pillow opencv-python-headless numpy scipy
python scripts/prepare-ryu-assets.py --source "<写真308>" --output public/private-assets/ryu/model-v1
python scripts/prepare-near-view-motion.py --front "<写真308>" --near "<写真310>" --assets public/private-assets/ryu/model-v1
python scripts/extract-head-motion.py --video "<動画3>" --clip-id video-3 --seed-second 3.6 --seed-box 150 310 300 290 --output public/private-assets/ryu/model-v1/motion-video-3.json
python scripts/extract-head-motion.py --video "<動画3>" --clip-id video-3-return --seed-second 8 --seed-box 180 330 300 280 --output public/private-assets/ryu/model-v1/motion-video-3-return.json
npm run dev
```

## ローカル比較

旧版は正面写真308と横顔写真349を半透明で重ね、切替途中に目鼻が二重になり、首と胴体の継ぎ目も目立った。新しい版は同条件に近い308と310に角度を限定し、対応点で顔の各部位を位置合わせしてから中間画像を作る。ローカルChromeの静止画で正面・中間・斜めを比較すると、鼻・目・耳が一組に見え、大きな横顔写真が突然現れる場面はなくなった。ただし切り抜きの左耳周辺には背景の残りが少しある。二枚の写真の毛並みや露出にも差があり、完全な3D回転ではない。

ブラウザで再生・一時停止・速度0.5倍・再開・正面復帰を確認した。再生時刻約1.7秒では33段階のうち30番目の姿勢と、動画追跡に基づく頭部移動が表示され、5.8秒では0番目の正面へ戻る。停止中は再生時刻が進まず、JavaScriptエラーは発生しなかった。幅390px・高DPIのタッチ画面でも再生でき、横方向のはみ出しはなかった。動画3を目視した「上がる→横へ向く→正面寄りへ戻る」の順序とは一致するが、出典映像のフレームとモデル姿勢の角度は一致計測できていない。

## まだできていないこと

動画3のカメラ移動・支える手と頭部の動きを完全には分離できない。yaw/pitch、目や口の時系列、耳単独の動きは未測定。動画851は候補として観察したが、この再生には含めていない。正面から小角度以外の姿勢、閉眼・開口の実写真、首の形の連続性は今後の課題。第1段階の画質確認を優先し、撫で操作と新モーションの連動は実装していない。

元写真・動画、生成した33枚の画像、追跡JSON、ローカルの比較スクリーンショットはGitHubと本番ビルドに含めない。公開するのはコードとこの匿名メモのみ。

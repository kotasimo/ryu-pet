# Issue #5: 動画003の自律再生と検証

動画003（16.17秒）の「下向き→頭上げ→画面左向きで保持→正面寄りへ復帰→下向き」を、既存の `/` で再生する。元動画には手が写っているが、接触が動作の原因とは判断していない。元映像、実写真、派生画像、追跡JSON、比較画像は非公開のローカル素材であり、Gitには含めない。

## T1: 変更前のベースライン

非公開写真を読み込んだChromeで、旧5.8秒版の0/25/50/75/100%を保存し、目視確認した。

| 位置 | 変更前の見た目と問題 |
|---|---|
| 0% | 正面。映像冒頭の下向き姿勢がない |
| 25% | 左寄りの顔に早く到達。動画003の頭上げ段階が独立していない |
| 50% | 左向きの静止が続く。本人の時間軸とは対応していない |
| 75% | すでに正面寄り。映像の復帰より早い |
| 100% | 冒頭と同じ正面。映像終盤の下向き姿勢がない |

旧版は写真308・310の中間顔を一枚ずつ描いていたため、目鼻の明瞭な二重像はなかった。首と胴体の接合には軽い継ぎ目があり、左向き角度は実映像より浅かった。

## T2: 出典と再生データ

`video-003-motion.ts` が動画ID、16.17秒の長さ、秒単位の**目視観察**、写真ビューに与える**仮の進行量**を別に保持する。上昇は約2〜3秒、左向きへの移行は約3.5〜5秒、保持は約5〜7秒、正面への復帰は約8〜10秒、下向きは約13〜15秒とした。これらは映像からの概略時刻で、3D角度の計測値ではない。画面の観察文にも実測がある時刻と欠測の時刻を表示する。

2Dの位置と面内回転は、動画003の短区間からローカルで追跡した値を別の非公開JSONから読む。今回追加した頭上げ区間は約2.6〜3.4秒で、信頼度しきい値を満たした5標本を使用した。既存の左向き・復帰の短区間も使用する。追跡区間の始点と終点を差し引いた残差を適用し、区間外の軌跡や向きは仮の補間とする。カメラ、手の遮蔽、動きブレがあるため、2D追跡値も頭部の純粋な3D運動ではない。

再生、一時停止、停止、シーク、0.5/1倍速、ループを確認できるようにした。

## T3: 外見の連続性

写真308を正面基準に、同じ撮影系列の写真309を頭上げ寄り、310を左向き寄りとして目・鼻・耳・頬・輪郭の対応点を合わせ、各33枚の中間姿勢を非公開で生成した。下向きは対応する同条件写真がないため、308から作った控えめな仮の2Dワープ33枚を使用した。どの時刻も**一枚の顔画像だけ**を描画し、向きが切り替わる時刻には正面フレームを通す。独立した口・耳・まばたきのアニメーションは付けていない。

## T4: 実映像との比較

`scripts/compare-video-003.py` は元動画の0/2/3/4/6/8/10/13/15秒と、同時刻のブラウザ画面を並べた非公開画像をローカルに出力する。動画とモデルは背景・撮影条件・画角が異なるため、数値の直接比較はしていない。

並列の目視では、頭上げ、左向きの保持、正面への復帰、下向きの**順序**は一致した。中間画像に二重の目・鼻は見えず、首元の大きな裂けも見えなかった。ただし動画4〜7秒の顔はモデルより明確に横を向き、動画10〜12秒の目はモデルより細い。動画0〜1秒と13〜15秒の鼻先もモデルより下を向く。現状の左向きと下向きは、顔の破綻を避ける範囲に抑えた再現であり、映像と同じ角度・表情には達していない。近い撮影条件の横向き、鼻先下向き、細目の写真が次に必要。

## T5: 動作確認と公開範囲

- `npm run build` と `python scripts/validate-model-assets.py` を実行。
- 実素材を読み込んだChromeで0/2/3/4/6/8/10/13/15秒の姿勢、再生・一時停止・停止・シーク・0.5倍速・ループを確認。
- 非公開素材を404にした状態で再生操作が無効になり、JavaScriptエラーが出ないことを確認。
- 390px幅・高DPIのChromeでも再生でき、横方向のはみ出しはなかった。`/pet` のキャンバスと `/analyze` の主要画面が開き、JavaScriptエラーは出なかった。
- 最終版の0/25/50/75/100%を再撮影し、一組の目鼻が続くことと、頭部と胸の接合に大きな裂けがないことを目視確認した。

実素材を含めない本番ビルドは写真モデルを再生しない。原本と生成した画像・追跡値を公開しない方針を優先する。飼い主の画面録画による品質レビューは別途必要。

再生成には写真308・309・310と動画003のローカルパスを実行時に渡す。追跡値と画像は `public/private-assets/ryu/model-v1/` に保存し、Gitの対象から除外する。旧版の生成手順は [自律モデルの検証](autonomous-model.md) に記載している。

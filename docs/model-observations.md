# モデル用の映像・表情観察

ローカル素材を目視で確認した制作メモ。時刻は約1〜2秒間隔で抽出したフレームに基づく概数で、動きの測定値ではない。素材本体や撮影場所、個人情報は含めない。素材番号はローカル分析表の番号。

## 写真

| 素材番号 | 観察できる形 | モデルへの使い方 |
| --- | --- | --- |
| 308 | 正面寄りの黒・茶・白の顔模様、耳、胸 | 現行モデルの基準写真 |
| 159、173、947 | 目を閉じた状態。顔の角度と照明が基準写真と異なる | 閉眼時の形の参照。直接貼るとずれるため、テクスチャ化は保留 |
| 162、632 | 大きく口が開いた状態 | 開口形状の参照。現行の小さな口の動きとは別の状態 |
| 349、326 | 横向きの鼻、頬、耳の輪郭 | 横顔の参照。正面写真から横向きの面を捏造しない |

## 動画の時系列

### 素材 3（約16秒）

| 時刻 | 画面上で確認できること |
| --- | --- |
| 0〜1秒 | 頭頂に手。顔はやや下向き。別の手が胴を支える |
| 2〜4秒 | 顔が上がり、画面左側へ向く。手は頭頂付近にある |
| 5〜7秒 | 横向きの顔を保つ。耳の独立した動きは判別困難 |
| 8〜10秒 | 顔が正面側へ戻る。頭頂の手は位置を変える |
| 11〜13秒 | 正面寄りで頭の高さが変化する |
| 14〜15秒 | 顔が下を向く。頭頂に手が残る |

### 素材 851（約32秒）

| 時刻 | 画面上で確認できること |
| --- | --- |
| 0〜2秒 | 首の側面に手。顔は横向き |
| 4〜6秒 | 鼻先が上を向く。首付近への接触が続く |
| 8〜10秒 | 顔が大きく横向きになり、奥側の顔が隠れる |
| 12〜14秒 | 顔が再び斜め上を向く |
| 16〜18秒 | 正面寄りへ向きが変わり、顔がやや下がる |
| 20〜22秒 | 顔が正面寄り。口元に動きが見える |
| 24〜26秒 | 舌が見えるフレームがある |
| 28〜30秒 | 頭頂付近へ手が移り、顔が横向きに変わる |

接触と姿勢変化は同時に見えるが、支える手、犬自身の動き、視点の影響がある。どの接触がどの反応を起こしたかは確定できない。現在のアプリで使用する撫でる方向、量、速度、閉眼率、耳の動き、呼吸周期はすべて仮設定。頬と耳への単独接触反応は未確認。
